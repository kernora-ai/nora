# Kernora — Coding Patterns

> This file is automatically updated by Kernora as it learns from your coding sessions.
> Patterns are extracted from session analysis and ranked by effectiveness.

## How Kernora Patterns Work

Kernora observes your coding sessions and extracts recurring patterns — approaches that consistently lead to successful outcomes. These are surfaced to your AI coding agent as context before every prompt, so the agent learns your team's conventions.

## Getting Started

Start coding with Kiro. After your first few sessions, Kernora will populate this file with patterns specific to your workflow:

- Code structure patterns (how you organize files, modules, tests)
- Error handling patterns (your team's approach to exceptions, retries, logging)
- API design patterns (naming conventions, response formats, authentication)
- Testing patterns (test structure, mocking strategies, coverage targets)

## Pattern Format

Each pattern includes:
- **Pattern name and description**
- **Code example** showing the pattern in use
- **Domains** where the pattern applies
- **Effectiveness score** based on how often it leads to successful sessions
