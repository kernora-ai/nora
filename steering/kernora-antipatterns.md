# Kernora — Anti-Patterns

> This file is automatically updated by Kernora. It captures mistakes, failed approaches,
> and patterns to avoid — learned from your coding sessions and bug fixes.

## How Kernora Anti-Patterns Work

When Kernora detects a bug fix, a reverted approach, or a pattern that led to problems, it records it here as an anti-pattern. Your AI agent sees this before every prompt, preventing it from repeating known mistakes.

## Getting Started

As you fix bugs and iterate on code, Kernora will populate this file with:

- Common mistakes in your codebase
- Approaches that were tried and abandoned
- Library-specific gotchas
- Performance pitfalls
- Security anti-patterns

## Anti-Pattern Format

Each anti-pattern includes:
- **What went wrong** — the problematic approach
- **Why it's wrong** — root cause
- **What to do instead** — the correct approach
- **Related bug** — link to the original issue if applicable
