# Run `nora_help`

In your IDE chat (with Nora MCP connected), ask:

```text
nora_help
```

Or invoke the `nora_help` MCP tool directly.

You get the exact tool list for **your** tier — 15 on Lite, up to 60 on Pro — not a memorized catalog. Use that list as the source of truth for what you can call today.
